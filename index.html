Charging states

Visual reference · 7 states

How each charge state looks on this device.

0 IDLE · 空闲

No cable connected · charger waiting

1 CONNECTED · READY

Cable plugged in · vehicle detected, ready to start

2 WAITING · WAIT

Negotiating with vehicle · scheduled or queued

3 CHARGING · 充电中

Active power flow · pulsing animation + breathing glow

4 STOPPED_BY_CHARGER

桩主动停

Charger paused · thermal / fault / scheduled stop

5 STOPPED_BY_EV

车主动停

Vehicle requested stop · battery full or driver action

6 COMPLETE · 充满

Charging finished · ready to disconnect

State codes match the device firmware enum. UI selects gauge color, animation, action button label, and primary CTA based on this code.
